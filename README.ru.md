# 🎮 BagaGame Launcher

**Русский** · [English](README.md)

**BagaGame Launcher** — лёгкий и быстрый органайзер игровой библиотеки в стиле Windows 11 Fluent. Он собирает установленные игры в одну аккуратную коллекцию с постерами, группировкой по сериям и жанрам, поиском и учётом наигранного времени — плюс полноэкранный режим **Big Picture** для телевизора и геймпада — вместо десятков ярлыков на рабочем столе.

Приложение написано на **C# / WPF** под **.NET Framework 4.7.2** и не использует сторонних UI-фреймворков: все контролы стилизованы вручную. Эта версия .NET уже входит в Windows 10 и 11, поэтому ставить рантайм не нужно, а весь лаунчер занимает около **1 МБ**.

---

## 📥 Установка

1. Откройте раздел **[Releases](https://github.com/bagabeer/BagaGame-Launcher/releases)** и скачайте архив последней версии (`v0.9.0`).
2. Распакуйте архив в любую папку, доступную для записи (например, `D:\BagaGame`).
3. Запустите **`BagaGame.exe`**.

Установщика нет — приложение работает сразу после распаковки. Это **один портативный `BagaGame.exe`**: все управляемые зависимости встроены внутрь, рядом не нужны DLL. Если рядом с `.exe` уже есть папка `BagaGameData`, лаунчер использует её (портативный режим). Для одиночного `.exe` на рабочем столе или в `Program Files` данные хранятся в `%LOCALAPPDATA%\BagaGame`, поэтому папка рядом с exe не появляется. Создай `BagaGameData` рядом с exe, если нужен полностью портативный режим.

> **Требования:** Windows 10 версии 1803+ или Windows 11. .NET Framework 4.7.2 уже включён в систему — ничего доустанавливать не нужно.
>
> Если Windows SmartScreen предупреждает о неизвестном издателе, нажмите **«Подробнее» → «Выполнить всё равно»**: файл не подписан сертификатом.

## ✨ Возможности

* **Big Picture.** Полноэкранный режим для телевизора с геймпадом и клавиатурой: крупные обложки, hero-арт, карусель и компактная сетка, разделы «Все игры / По алфавиту / Жанры / Избранное», фильтр по жанрам, избранное и панель «Подробнее». Открывается на мониторе библиотеки, скрывает курсор при вводе с геймпада и запускает игры на этом же экране.
* **Геймпад и клавиатура.** D-pad и стик, Q/E и LB/RB переключают разделы; A — играть, X — подробнее, Y — избранное, B — выход. Контроллер может открывать Big Picture автоматически.
* **Избранное.** Отмечайте игры звёздочкой в библиотеке или в Big Picture и фильтруйте коллекцию по ним.
* **Обновления.** Лаунчер проверяет новые версии, показывает скрываемую карточку в сайдбаре, а проверку можно отключить в настройках.
* **Глубокое сканирование.** Находит игры в выбранных папках, включая нестандартные структуры и вложенные каталоги, отсеивая служебные `.exe` (`unins`, `vcredist`, `crashhandler` и подобные).
* **Интеграция с магазинами.** Импортирует библиотеки **Steam**, **Epic Games** и **GOG Galaxy**.
* **Обложки и жанры.** Подтягивает постеры и жанры из интернета, кэширует их локально и умеет работать без сети.
* **Группировка.** Режимы «Все», «А–Я», «Жанры» и «Серии»: франшизы (*Resident Evil*, *Dying Light*, *Silent Hill*…) собираются автоматически.
* **Учёт времени.** Считает наигранные часы для игр, запущенных через лаунчер, и показывает их прямо на карточке.
* **Сворачивание в трей.** При запуске игры окно уходит в системный трей, а после её закрытия **автоматически возвращается** на экран.
* **Русский и английский интерфейс.** Переключается в настройках без перезапуска и запоминается.
* **Тёмная и светлая темы.** На Windows 11 используется нативный эффект Mica; на Windows 10 — аккуратный непрозрачный фон.
* **Сетка и список.** Два режима отображения библиотеки, быстрый поиск (`Ctrl+F`) и пересканирование (`F5`).
* **Ручное добавление.** Можно добавить отдельную папку игры или конкретный `.exe`, а также переименовать, скрыть или удалить игру через контекстное меню.
* **Своя обложка.** Правый клик по карточке позволяет загрузить свою картинку и кадрировать её в рамке 2:3 с перетаскиванием и масштабом. Любая обложка сохраняется как постер 600×900; при включённом SteamGridDB можно также выбрать обложку сообщества.
* **SteamGridDB.** Дополнительный источник обложек по бесплатному API-ключу; включается в настройках и заменяет встроенный поиск Steam на обложки сообщества.
* **Один экземпляр.** Повторный запуск не открывает второе окно, а разворачивает уже работающее.
* **Надёжное сохранение.** Библиотека пишется атомарно (с резервной копией), а при недоступном диске карточка игры остаётся на месте с пометкой «Путь недоступен» и кнопкой «Указать папку заново».

## 🗂 Данные приложения

```text
<папка с BagaGame.exe>\BagaGameData\library.json   — библиотека, настройки, время, скрытые игры
<папка с BagaGame.exe>\BagaGameData\covers\        — постеры, heroes\, metadata-v3.json и storeids.json
<папка с BagaGame.exe>\BagaGameData\covers-custom\ — обложки, выбранные пользователем (600×900)
```

Если папка рядом с `.exe` недоступна для записи или её нет, используется `%LOCALAPPDATA%\BagaGame`. Кэш обложек можно перенести в любую папку отдельно: Настройки → **Кэш обложек** → **Изменить**.

| Ключ `library.json` | Назначение |
|---|---|
| `Hidden` | Скрытые игры |
| `CustomTitles` | Пользовательские названия |
| `Folders` | Папки для сканирования |
| `ManualGames` | Игры, добавленные вручную |
| `Genres` | Кэш жанров (хранятся канонические английские названия) |
| `Playtime` | Наигранное время в секундах |
| `LastPlayed` | Время последнего запуска для порядка «недавние» |
| `Favorites` | Избранные игры библиотеки и Big Picture |
| `CustomCovers` | Пользовательские обложки в `covers-custom` |
| `UseSteamGridDb`, `SteamGridDbApiKey` | Источник SteamGridDB и API-ключ |
| `Theme`, `Language`, `GridView`, `DownloadCovers`, `CacheDirectory` | Настройки интерфейса |
| `BigPictureOnGamepad`, `BigPictureSounds` | Настройки Big Picture |

## 🛠 Сборка из исходников

Нужен только **.NET SDK 8+**: он собирает проект под .NET Framework 4.7.2 через reference assemblies, Visual Studio не обязательна.

```powershell
dotnet build BagaGame.csproj -c Release
dotnet run --project BagaGame.csproj
```

Готовый `.exe` появится в `bin\Release\net472\` и **работает сам по себе**: Costura встраивает все управляемые зависимости, поэтому в папке остаётся только `BagaGame.exe`. Установщик и отдельный набор DLL не нужны.

### Структура проекта

```text
BagaGame.csproj                     — net472, WPF + WinForms (только трей), без сторонних UI-пакетов
App.xaml / App.xaml.cs              — запуск, единственный экземпляр, язык, тема
MainWindow.xaml / .xaml.cs          — окно, карточки, поиск, горячие клавиши, трей
Views/BigPictureWindow.xaml / .cs   — полноэкранный режим, разделы, подсказки, панель «Подробнее»
ViewModels/MainViewModel.cs         — фильтрация, группы, статусы, обложки
ViewModels/BigPictureViewModel.cs   — разделы, жанры, избранное и текст «Подробнее»
Models/Game.cs                      — модель игры и локализованные подписи
Services/GameLibraryService.cs      — сканер Steam / Epic / GOG / папок, обложки и жанры
Services/PlaytimeTracker.cs         — учёт времени и событие завершения игры
Services/LibraryStore.cs            — атомарное сохранение library.json
Services/LibraryGrouping.cs         — группы «А–Я», «Жанры», «Серии»
Services/Localization.cs            — RU/EN и словари строк
Services/Input/GamepadService.cs    — опрос XInput и команды геймпада
Services/Audio/UiSounds.cs          — звуки навигации и избранного
Services/BigPictureTransition.cs    — анимация входа/выхода Big Picture
Services/TrayIcon.cs                — иконка и меню в трее
Services/AppPaths.cs                — портативная папка данных
Themes/                             — палитры, стили контролов, Strings.ru/en.xaml
Controls/                           — собственные Fluent-контролы (окно, кнопки, переключатели)
Compat/                             — полифиллы для современного C# на net472
```

### Версия 0.9.0 — Big Picture

**Big Picture — полноэкранный режим для телевизора**
* Hero-арт, крупные обложки, звуки и анимированный вход/выход со сплэшем запуска.
* Геймпад (XInput) и клавиатура; подключённый контроллер может открывать Big Picture автоматически.
* Управление: D-pad/стик — навигация, **A** — играть, **X** — подробнее, **Y** — избранное, **B** — выход; **Q/E** и **LB/RB** переключают разделы.
* Открывается на мониторе библиотеки, масштабируется под 4K и следует светлой и тёмной теме.
* Плашки разделов парят над hero-артом; карусель и компактная сетка используют один и тот же выбор.
* D-pad вниз переключает карусель и сетку, стик листает обложки, выбранная обложка приподнимается.
* Сетка прокручивается к выбранной карточке и не выпускает стик за видимые ряды.
* Курсор мыши скрывается при вводе с геймпада и возвращается только при реальном движении мыши.
* Подсказки геймпада и клавиатуры нарисованы векторными глифами, включая D-pad.

**Разделы, жанры и избранное**
* Разделы **«Все игры», «По алфавиту», «Жанры»** и **«Избранное»**; переключение Q/E, LB/RB или плашками.
* Разделы Big Picture независимы от библиотеки, режим всегда открывается на «Все игры». В библиотеке остаётся группировка по сериям.
* Каждое переключение раздела начинается с первой игры естественного порядка — список больше не переставляется вокруг выбранной игры.
* Панель жанров с количеством игр, стрелками и фильтрацией; активный жанр подсвечен, у переключения свой звук.
* Жанры новых игр подгружаются автоматически и в Big Picture, и в библиотеке.
* Избранное: **Y** добавляет или убирает игру, со своими звуками и всплывающим уведомлением. У раздела «Избранное» есть отдельное пустое состояние.

**Панель «Подробнее»**
* Полное описание из магазина, время игры сверху и папка игры ниже.
* Текст прокручивается стиком, стрелками и Page Up / Page Down.
* Панель модальная: обложки, разделы и сетка не меняются, пока она открыта.
* Всегда открывается с начала текста и закрывается по **B**, **X**, **Space**, **Enter**, **Esc** или клику мимо.
* Скрытый курсор остаётся скрытым при открытии панели.

**Библиотека и запуск**
* Избранное в библиотеке: фильтр по звёздочке и пункт контекстного меню.
* Проверка обновлений со скрываемой карточкой в сайдбаре и переключателем в настройках.
* Игры из Big Picture открываются на мониторе Big Picture, игры из библиотеки — на мониторе лаунчера.
* Библиотека всегда открывается на «Все игры», выбор группировки больше не сохраняется.
* Свечение выбранной обложки восстановлено и больше не обрезается сверху, слева и справа.
* В строках списка убрана круглая кнопка добавления обложки; текстовая подсказка осталась.
* Контекстное меню и меню текстового поля оформлены в теме приложения.
* Размер окна по умолчанию вмещает два полных ряда карточек.
* Сплэш запуска больше не отбрасывает внешнюю тень; рамка и свечение логотипа остались.

### Версия 0.8.0 — обновление обложек

**Выбор обложки**
* Правый клик по карточке → **«Сменить обложку»**.
* До 36 обложек сообщества из SteamGridDB для выбранной игры.
* Можно загрузить свою картинку: JPG, PNG или BMP до 12 МБ.
* Картинку можно двигать мышью и масштабировать колесом в рамке 2:3.
* Любая обложка сохраняется как постер 600×900, поэтому карточки не разъезжаются.
* **«Вернуть стандартную»** убирает свою обложку и возвращает автоматическую.
* Выбор сохраняется после перезапуска.

**SteamGridDB**
* Новый раздел в настройках: включение, поле API-ключа и кнопка **«Получить ключ»**.
* Показываются обложки только найденной игры, без чужих игр.
* Зелёная плашка **«RU · нужен VPN»** напоминает, что в России SteamGridDB может требовать VPN.

**Библиотека и карточки**
* У игры без постера в правом верхнем углу появляется подсказка **«Добавить обложку»**; фон проявляется при наведении.
* Скрытые игры можно восстанавливать по одной; список раскрывается маленькой стрелкой и показывает все скрытые игры.
* У скрытых игр показывается папка или магазин, как в основном списке.
* Окно выбора обложки стало компактным: четыре обложки в ряд, без пустоты справа.
* На экране кадрирования один понятный заголовок и настоящая рамка 2:3.
* Убраны лишние подписи и зелёное выделение текста при открытии окна.

**Трей, язык и надёжность**
* Окно сворачивается в трей при запуске игры и **само возвращается**, когда игра закрывается.
* Повторный запуск лаунчера открывает уже работающее окно, а не вторую копию.
* Переключение RU/EN без перезапуска с сохранением выбора.
* Библиотека сохраняется атомарно с резервной копией; портативные данные лежат в `BagaGameData`.

**Исправления по отзывам сообщества**
* Удалённые игры больше не возвращаются после следующего сканирования.
* Дубликаты из нескольких `.exe` одной папки схлопываются в одну карточку.
* Трекер времени больше не засчитывает чужой процесс с похожим именем и не накладывает свои тики.
* Принудительный TLS 1.2, отменяемое сканирование и проверка путей без совпадений `Foo` → `Foobar`.

**Внешний вид**
* Новая иконка приложения — зелёный геймпад.
* Убраны светящаяся рамка окна и лишняя обводка диалогов.
* Мелкие правки отступов, размеров кнопок и текста.
* Портативная сборка в один файл: все управляемые зависимости встроены в `BagaGame.exe`.

## ⚠️ Известные ограничения

* **Жанры.** Определяются через Steam Store API; неизвестные игры попадают в группу «Другое».
* **Пользовательские папки.** Поиск основан на `.exe`, поэтому служебные утилиты иногда попадают в библиотеку — их можно скрыть или удалить через контекстное меню.
* **Mica.** Эффект доступен только на Windows 11 (build 22000+). На Windows 10 используется обычный фон темы.
* **Античиты и лаунчеры.** Если игра запускается через сторонний лаунчер (Ubisoft Connect, Rockstar Launcher и т. п.), трекер может не увидеть процесс и не засчитать время.
